# Vaper Forge

The Vaper Forge site helps people plan a visit to a local shop: check hours and directions, browse product categories, search common questions, or ask the store assistant about basic product questions.

## Build and inventory decisions

The front end uses HTML5, CSS3, and vanilla JavaScript. I put visit details and the 21+ requirement where they are easy to find. Product availability changes quickly, so the site tells people to call about a specific item instead of presenting a made-up live inventory count.

This repository contains public project notes, not the production site source.
